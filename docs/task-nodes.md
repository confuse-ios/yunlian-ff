# 任务节点

任务节点是云链分发分布式架构中的**执行层**。Web 控制台负责创建任务与调度，实际的 IPA 处理、Apple 账号交互、签名运算等工作均由任务节点完成。使用前需为 Apple 账号绑定节点，或通过公共节点授权获得执行能力。

在线阅读：[任务节点](https://yunlian-ff.com/docs/task-nodes) · 配置入口：[任务节点管理](https://yunlian-ff.com/console/nodes)

## 节点的作用

由于 Apple 开发者操作（登录验证、证书申请、IPA 上传等）需要在真实或虚拟化的 macOS 环境中执行，平台将这些重计算任务下放至任务节点，而非在 Web 服务器上直接处理。每个 Apple 账号可绑定一个任务节点，该节点负责该账号相关的全部自动化操作。

```text
Web 控制台 → 任务调度 → 任务节点 → Apple 服务
创建任务      路由至已绑定节点    执行 IPA / 证书 / 2FA    App Store Connect 等
```

## 节点能做什么

| 任务类型 | 说明 |
| --- | --- |
| Apple 账号 2FA 认证 | 接收并处理 Apple 开发者账号的双因素验证码，完成登录与会话维持 |
| IPA 上传 | 执行 TestFlight 上传、App Store 构建上传等 Transporter 相关操作 |
| IPA 重签名 | 在节点本地完成 IPA 解包、替换证书与描述文件、重新打包签名 |
| 证书与描述文件 | 创建开发者证书、生成 Provisioning Profile，与 Apple 开发者 portal 交互 |
| IPA 解析与托管 | 解析内测分发 IPA 的包信息，协助文件托管与 CDN 分发 |
| IPA 相似度分析 | 对比两个 IPA 的代码、Framework 与资源文件差异，生成分析报告 |

> **为什么必须配置节点？**
>
> TestFlight 上传、重签名、证书创建等功能均依赖任务节点执行。若 Apple 账号未绑定节点，且没有已授权的公共节点，相关操作将无法进行。建议在上架引导或功能使用前，优先完成节点配置。

## 公共节点 vs 自控节点

平台提供两种节点类型：**公共节点**由平台统一运维，适合快速上手；**自控节点**（也称私有节点）由用户自行部署，适合对数据安全与环境隔离有更高要求的场景。

### 公共节点

- 平台提供的共享任务节点，开箱即用
- 在「任务节点 → 公共节点」中申请授权
- 管理员审批通过后，可绑定到 Apple 账号
- 无需自备服务器，无需下载安装节点程序
- 适合个人开发者、初次使用、轻量测试场景

### 自控节点（私有）

- 部署在用户自有 Mac 或服务器上的私有节点
- 需 VIP 套餐含「创建自控节点」权限
- 下载节点程序，配置授权码后即可上线
- 支持环境虚拟化，可管理多套虚拟设备身份
- IPA 与证书数据在本地处理，不经过公共节点

## 详细对比

| 对比项 | 公共节点 | 自控节点（私有） |
| --- | --- | --- |
| 部署方式 | 平台统一部署维护，用户无需自备服务器 | 用户下载节点程序，部署在自己的 Mac / 服务器上 |
| 使用门槛 | 注册即可申请授权，审批通过后即可使用 | 需开通 VIP（含「创建自控节点」权限），有数量上限 |
| 数据路径 | IPA 与证书材料经平台公共节点处理 | 任务在自有机器上执行，数据不经过公共节点 |
| 环境虚拟化 | 不支持 | 支持，可配置虚拟设备身份（序列号、机型、MAC 等） |
| 绑定方式 | 申请授权后，绑定到 Apple 账号即可调度 | 创建后直接绑定，无需平台审批 |
| 在线要求 | 由平台保障节点可用性，用户只需关注授权状态 | 需自行保持节点程序运行，离线时无法执行任务 |
| 适用场景 | 个人开发者、小团队、快速上手 | 对数据安全敏感、需环境隔离、大规模稳定生产 |

## 如何配置

### 使用公共节点

1. **进入任务节点页面**  
   控制台 → 任务节点 → 公共节点 Tab。
2. **申请授权**  
   选择可用公共节点，点击「申请授权」，等待管理员审批（状态：待审批 → 已授权）。
3. **绑定到 Apple 账号**  
   授权通过后，在「苹果账号」管理页为账号绑定该公共节点，即可开始上传、签名等操作。

### 创建自控节点

1. **确认 VIP 权限**  
   开通含「创建自控节点」权限的 VIP 套餐，查看可创建节点数量上限。
2. **创建节点**  
   控制台 → 任务节点 → 点击「新增自控节点」，填写节点名称、地区、语言、时区。
3. **下载并安装节点程序**  
   点击「下载节点程序」，在 Mac 上安装并启动，使用授权码完成注册上线。
4. **绑定 Apple 账号**  
   节点在线后，在苹果账号管理页绑定该自控节点。VIP 过期后节点会暂停，续费后可重新启用。

## 环境虚拟化（自控节点专属）

自控节点支持**环境虚拟化**能力，可为每个节点配置多套虚拟设备身份，包括用户名、序列号、MLB、ROM、机型、MAC 地址等。在执行 Apple 开发者操作时，节点可使用不同的虚拟身份，进一步降低多账号之间的环境关联风险，适合矩阵化运营场景。

## 注意事项

- **节点必须在线**  
  绑定自控节点后，若节点程序未运行或离线，该账号的上传、重签名等任务将无法执行。请确保节点程序持续运行。
- **VIP 与自控节点**  
  自控节点依赖 VIP 权限维持启用状态。VIP 过期后节点自动暂停，续费或重新开通 VIP 后可恢复。
- **公共节点授权**  
  公共节点授权需管理员审批，审批期间状态为「待审批」。可在「我的授权」Tab 查看进度或取消申请。
- **一账号一节点**  
  每个 Apple 账号建议绑定一个固定节点执行任务，频繁更换节点可能影响会话稳定性。

公共节点零部署成本，申请授权即可使用。自控节点数据本地化，支持环境虚拟化。两种方式可并存，按账号需求灵活选择。
