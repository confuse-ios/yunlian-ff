# 如何解决账号关联

Apple 会通过 IP 地址、设备指纹、证书信息、支付信息等多维度信号判断多个开发者账号是否属于同一运营主体。一旦关联，可能导致批量封号或审核受限。云链分发通过**「一账号一 IP」**的隔离策略，从根本上降低关联风险。

在线阅读：[账号关联隔离](https://yunlian-ff.com/docs/account-isolation) · 使用平台：[云链分发](https://yunlian-ff.com)

## 隔离原理

### 独立出口 IP

每个 Apple 开发者账号绑定一条独立的 IP 隔离策略（住宅 IP 或固定 IP 代理）。访问 App Store Connect、上传构建、提交审核等所有 API 请求均通过该 IP 发出。

### 环境隔离

账号的登录会话、Cookie、API Token 在平台内独立存储，不同账号之间不共享任何网络环境或会话数据。

### 证书隔离

每个账号的证书、描述文件、Provisioning Profile 独立管理，签名材料不会交叉使用。

## 配置步骤

1. **获取 IP 隔离策略**  
   在「IP 隔离策略」页面添加代理，或从平台购买住宅 IP 代理（推荐地区与 Apple 账号注册地区一致）。
2. **绑定到 Apple 账号**  
   在「苹果账号」管理页，为每个账号单独绑定一条 IP 策略，确保不同账号使用不同 IP。
3. **启用浏览器扩展代理（可选）**  
   安装 App Store 访问代理浏览器扩展，在本地浏览器中也能通过隔离 IP 访问 App Store Connect。
4. **验证隔离生效**  
   绑定后，平台会在账号详情中显示当前出口 IP，确认与预期一致后再进行上传或提审操作。

## 重要注意事项

- 同一 IP 策略**不要**绑定到多个 Apple 账号，否则失去隔离意义。
- 优先选择**住宅 IP**或**固定 IP**，避免使用频繁轮换的数据中心 IP。
- 代理 IP 的地区应与 Apple 账号注册地区保持一致。
- IP 策略启用后，App Store Connect 访问流量会计入 VIP 配额中的「代理流量」。
- 除 IP 外，还需注意支付信息、联系人、Bundle ID 命名规范等其他关联因素。
