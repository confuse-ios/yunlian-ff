# IPA 相似度分析

IPA 相似度分析（也称 IPA 对比）允许你上传两个 IPA 文件，平台自动对比两者的代码、Framework、资源文件差异，输出整体相似度百分比和详细分析报告，帮助评估 4.3 拒审风险与版本差异化程度。

在线阅读：[IPA 相似度分析](https://yunlian-ff.com/docs/ipa-similarity) · 立即分析：[yunlian-ff.com/similarity-analysis](https://yunlian-ff.com/similarity-analysis)

## 功能概述

当 App 被 Apple 以 **Guideline 4.3（Design: Spam）** 拒审时，通常意味着审核团队认为该 App 与已有 App 过于相似。通过 IPA 对比功能，你可以在提审前量化两个 IPA 之间的相似程度，提前发现潜在风险并针对性优化。

| 场景 | 说明 |
| --- | --- |
| 4.3 拒审评估 | 提交 App Store 前，对比新旧版本或竞品 IPA，评估被 4.3（重复 App）条款拒审的风险 |
| 分身小包差异化 | 运营多个相似 App 时，验证各版本之间的代码与资源差异是否足够 |
| 版本迭代对比 | 对比相邻两个版本的 IPA，确认改动范围符合预期，避免意外引入高相似度内容 |
| 外包交付验收 | 验收外包团队交付的 IPA 是否与原始版本存在过度相似或代码复用问题 |

## 使用流程

1. **进入分析页面**  
   从首页「IPA 相似度分析」或控制台「IPA相似度分析 → 上传分析」进入功能页。
2. **上传两个 IPA 文件**  
   分别上传需要对比的 IPA 文件 1 和 IPA 文件 2。单文件大小受 VIP 套餐限制（普通用户默认 100MB）。
3. **提交分析任务**  
   点击「开始分析」，平台将任务分发至任务节点进行深度对比，可在页面查看上传与分析进度。
4. **查看结果**  
   分析完成后，在控制台任务列表中查看整体相似度百分比，并下载 ZIP 格式的详细分析报告。
5. **管理历史记录**  
   所有分析任务保存在控制台，支持查看详情、下载结果和删除历史记录。

## 分析维度

| 分析维度 | 说明 |
| --- | --- |
| 可执行文件 | 对比 Mach-O 二进制文件的代码段差异，识别核心逻辑相似程度 |
| Framework | 分析嵌入的动态库与 Framework 的文件列表及内容差异 |
| 资源文件 | 对比图片、音频、配置文件等资源的内容与结构差异 |
| Info.plist | 检查 Bundle ID、版本号、权限声明等元数据差异 |
| 整体相似度 | 综合以上维度计算整体相似度百分比，辅助 4.3 风险评估 |

## 注意事项

- **IPA 导出方式**  
  上传的 IPA 请使用 **App Store 配置描述文件**导出，不要使用 Ad-Hoc 或 Developer 配置描述文件导出，否则可能影响分析准确性。
- **配额消耗**  
  每次分析任务消耗 1 次「IPA 相似度分析」配额。部分 VIP 套餐不含此配额，需升级套餐或购买加油包。
- **分析耗时**  
  分析在任务节点上异步执行，IPA 越大耗时越长。提交后可在控制台查看任务状态（等待中 / 处理中 / 已完成 / 失败）。
- **结果解读**  
  相似度百分比仅供参考，Apple 审核决策还涉及 UI 设计、功能描述、元数据等多维度因素。建议结合 [上架合规服务](compliance-service.md) 进行综合评估。

## 与 4.3 审核的关系

4.3 条款主要针对功能、UI、内容高度重复的 App。IPA 相似度分析从**技术层面**量化二进制差异，帮助判断代码和资源层面的重复程度。若相似度较高，建议从 UI 改版、功能差异化、元数据优化等方向降低拒审风险。
