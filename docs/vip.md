## 资源配额说明

每项可计量功能均对应独立的资源配额。配额在 VIP 套餐中按**月**或**年**重置，未用完的配额**不累计**到下周期。可在个人中心查看各项配额的已用 / 剩余情况。

| 配额类型 | 计量单位 | 作用说明 | 重置周期 |
| --- | --- | --- | --- |
| IPA 上传次数 | 次 | TestFlight 上传、App Store 构建上传等操作消耗 | 按月 |
| App Store Connect 流量 | GB | 启用 IP 隔离方案后，访问 App Store Connect API 产生的流量 | 按月 |
| 内测应用下载 | 次 | 内测分发链接被用户下载安装时消耗 | 按月 |
| 重签名次数 | 次 | 每次 IPA 重签名任务消耗 1 次 | 按月 |
| IPA 相似度分析 | 次 | 4.3 风险分析、版本差异对比时消耗 | 按月 |

## 加油包的作用

当某项资源配额在周期内提前耗尽，无需升级整个 VIP 套餐，可单独购买对应类型的**加油包**即时补充配额。加油包购买后立即生效，配额叠加到当前周期剩余额度中。

| 加油包类型 | 适用场景 | 购买方式 |
| --- | --- | --- |
| IPA 上传加油包 | TestFlight / App Store 上传次数临时不足 | 控制台或功能页弹窗购买 |
| 代理流量加油包 | App Store Connect 访问流量超出套餐 | IP 隔离策略页购买 |
| 内测下载加油包 | 内测用户量突增、下载次数不够 | 内测应用管理页购买 |
| 重签名加油包 | 批量重签名需求超出月度配额 | 重签名功能页购买 |
| 相似度分析加油包 | 4.3 分析需求超出套餐配额 | 相似度分析页购买 |
