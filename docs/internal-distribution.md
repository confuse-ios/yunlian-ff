# 内测应用分发

内测应用分发允许你上传 IPA 文件，平台自动生成下载链接和二维码，测试用户通过 Safari 即可安装，无需经过 TestFlight 审核，适合快速迭代和小范围测试。

在线阅读：[内测应用分发](https://yunlian-ff.com/docs/internal-distribution) · 使用平台：[云链分发](https://yunlian-ff.com)

## 使用流程

1. **上传 IPA 文件**  
   进入「内测应用分发」页面，拖拽或选择 IPA 文件上传。文件大小受 VIP 套餐限制（普通用户默认 100MB，VIP 可提升上限）。
2. **等待解析与托管**  
   平台任务节点自动解析 IPA 包信息（Bundle ID、版本号、图标等），并将文件托管到 CDN 加速节点。
3. **获取下载链接**  
   上传成功后生成唯一下载链接和二维码，可直接分享给测试用户。
4. **用户安装**  
   测试用户在 iOS 设备 Safari 中打开链接，点击安装即可。首次安装需在「设置 → 通用 → VPN 与设备管理」中信任开发者证书。
5. **版本管理**  
   在控制台「内测应用」页面查看所有已上传版本，管理有效期、下载统计和链接状态。

## 注意事项

- **证书类型要求**  
  IPA 必须使用 Ad-Hoc 或 Enterprise（企业签）证书签名，App Store 分发证书签名的 IPA 无法通过此方式安装。
- **设备 UDID 限制**  
  Ad-Hoc 证书签名的 IPA 仅能在 Provisioning Profile 中已注册的设备上安装。请提前通过 [获取 UDID](get-udid.md) 收集测试设备 UDID 并添加到描述文件。
- **有效期管理**  
  内测应用链接有有效期限制（VIP 套餐可配置，默认 7 天）。过期后链接失效，需重新上传或续期。
- **下载配额**  
  每次用户成功下载安装消耗 1 次「内测应用下载」配额。配额不足时可购买加油包补充。详见 [VIP 与配额](vip.md)。
- **与 TestFlight 的区别**  
  内测分发无需 Apple 审核，即传即装，但无法使用 TestFlight 的崩溃报告、反馈收集等官方测试工具。适合小团队快速验证，大规模测试建议配合 [TestFlight Beta](testflight-beta.md) 使用。
- **企业签合规**  
  使用企业证书分发需确保符合 Apple 企业开发者计划的使用条款，不得面向公众分发或用于 App Store 替代方案，否则可能导致证书吊销。
